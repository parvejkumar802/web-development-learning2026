### 💻 Code Examples

#### HTML Structure
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
</head>
<body>
    <!-- Content here -->
</body>
</html>
```

#### CSS Flexbox Centering
```css
body {
    display: flex;
    justify-content: center;    /* Horizontal centering */
    align-items: center;        /* Vertical centering */
    min-height: 100vh;          /* Full viewport height */
}
```

#### Card Design with Shadow
```css
.card {
    width: 90%;
    max-width: 600px;
    background: #1e293b;
    padding: 40px;
    border-radius: 20px;
    box-shadow: 0 20px 50px rgba(0, 0, 0, 0.4);
}
```

#### Button Styling
```css
.button {
    display: inline-block;
    padding: 12px 24px;
    background: #38bdf8;
    border-radius: 8px;
    text-decoration: none;
    font-weight: bold;
    transition: background 0.3s;  /* Smooth hover effect */
}

.button:hover {
    background: #8B0000;
}
```

### 🔍 Key Learning Points
- ✅ `box-sizing: border-box` helps with responsive design
- ✅ `max-width` maintains layout on large screens
- ✅ Viewport meta tag is essential for mobile responsiveness
- ✅ Color scheme matters for user experience
- ✅ Hover states improve interactivity
